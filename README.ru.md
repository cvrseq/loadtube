LoadTube — небольшое приложение на SwiftUI, которое делает удобным `yt-dlp` и `ffmpeg`:

- вставили ссылку, выбрали качество, нажали **«Скачать»**;
- файл лежит в папке загрузок, с тегами и готов к воспроизведению;
- Spotify, Tidal, Instagram и TikTok обрабатываются отдельно, а не по принципу «может, сработает».

Приложение рассчитано на личное использование, работает на macOS 14+ и не отправляет данные никуда, кроме самих сайтов.

## Пресеты качества

| Пресет | Что получается | QuickTime |
|---|---|---|
| **Максимум** | Лучшее видео + лучший звук в оригинальных кодеках (YouTube может отдать AV1/VP9/Opus) | Может не открыться; выбирайте MP4-пресеты |
| **4K MP4** | До 4K в MP4; AV1/VP9 перекодируется в HEVC (H.265) через VideoToolbox | ✅ |
| **1080p MP4** | Full HD в MP4, всегда H.264 + AAC | ✅ |
| **MP3** | Только звук в лучшем доступном качестве, с обложкой и ID3-тегами | ✅ |

> Для Instagram и TikTok показываются только **«Максимум»** и **«MP3»**. Обе площадки отдают максимум 1080p, поэтому «Максимум» и так означает лучшее доступное качество.

## Установка

### Готовый DMG

1. Откройте `LoadTube.dmg`.
2. Перетащите **LoadTube** в папку **Applications**.
3. Запустите приложение. Если macOS говорит, что разработчик не подтверждён: правой кнопкой по **LoadTube** → **«Открыть»** → **«Открыть»**. Приложение подписано ad-hoc, без Developer ID и нотаризации.
4. При первом запуске нажмите **«Установить автоматически»** — приложение само скачает `yt-dlp` и `ffmpeg` (~120 МБ). Homebrew не нужен.

Готовый установщик лежит в `dist/LoadTube.dmg` — его можно передать другому человеку или выложить. Внутри также есть короткая инструкция «Первый запуск».

### Требования

- macOS 14 (Sonoma) или новее.
- Интернет для первого запуска и самих загрузок.
- **Homebrew не обязателен**, но поддерживается как резервный способ установки.
- **Tidal** — нужен собственный аккаунт. Lossless (FLAC) требует тарифа HiFi или Max; на Free-тарифе Tidal может отдавать только фрагменты. Python для Tidal не нужен: всё работает внутри LoadTube.
- Для сборки из исходников: Xcode Command Line Tools / Swift 5.9+.

## Сборка из исходников

```bash
make app       # собрать build/LoadTube.app (universal: arm64 + x86_64)
make run       # собрать и запустить
make install   # собрать и установить в /Applications
make dmg       # собрать dist/LoadTube.dmg для распространения
make clean     # удалить артефакты сборки
```

Сразу установить:

```bash
make install
```

Собрать DMG для передачи другим людям:

```bash
make dmg
open dist/LoadTube.dmg
```

## Использование

1. Запустите **LoadTube**.
2. Вставьте ссылку на видео, плейлист или трек (можно перетащить её в окно).
3. Выберите качество и нажмите **«Скачать»** (или Enter).
4. Готово: файл лежит в выбранной папке, уведомление появится справа сверху.

При первом запуске, если в системе нет `yt-dlp` и `ffmpeg`, приложение покажет экран установки и скачает портативные сборки в `~/Library/Application Support/LoadTube/bin`. Если Homebrew установлен, можно воспользоваться и им.

## Instagram и TikTok

LoadTube понимает ссылки:

- `instagram.com/reel/...`, `instagram.com/reels/...`, `instagram.com/p/...`
- `tiktok.com/@user/video/...`, а также короткие `vm.tiktok.com/...` и `vt.tiktok.com/...`

Для этих источников доступны только пресеты **«Максимум»** и **«MP3»** — чипы 4K/1080p скрыты, потому что площадки отдают максимум 1080p.

- **Instagram** — видео берётся из оригинального потока без никнейм-вотермарки, звук подклеивается автоматически.
- **TikTok** — приложение намеренно исключает служебный формат `download`, в котором TikTok запекает водяной знак. Остальные playback-потоки чистые, содержат звук и отдаются вплоть до 1080p.

После скачивания файл проверяется на совместимость с QuickTime: HEVC помечается тегом `hvc1` (без перекодирования), неподдерживаемый звук перекодируется в AAC, лишние дорожки убираются. Если файл уже совместим, обработка не запускается.

### Cookies браузера

Instagram ограничивает анонимный доступ, а TikTok может требовать вход для закрытых и «чувствительных» видео. Откройте **Настройки → Instagram и TikTok → Cookies браузера** и выберите браузер, в котором вы вошли на `instagram.com` и `tiktok.com`.

| Браузер | Что может запросить macOS |
|---|---|
| **Safari** | **Полный доступ к диску** для LoadTube (Системные настройки → Конфиденциальность и безопасность). Проверка — кнопкой **«Проверить доступ»**. |
| **Chrome / Edge / Brave** | Однократный запрос доступа к «Связке ключей» — разрешите его. |
| **Firefox** | Ничего дополнительно. |

Если выбранный браузер недоступен, приложение автоматически попробует другой установленный браузер; если не выйдет — скачает без cookies и покажет предупреждение. Cookies используются **только** для Instagram и TikTok.

## Spotify

Spotify отдаёт музыку только через DRM, поэтому скачать звук напрямую нельзя. LoadTube:

1. Достаёт название, исполнителя и обложку из публичных метаданных Spotify.
2. Ищет этот трек на YouTube (`ytsearch1`).
3. Скачивает лучший доступный звук и конвертирует его в MP3 VBR.
4. Переименовывает файл в `Исполнитель - Название` и подставляет обложку и ID3-теги.

> Это **не оригинальный поток Spotify 320 kbps**. Качество ограничено источником (обычно Opus 128–160 kbps на YouTube), поэтому итоговый MP3 — максимально возможный из доступного, но не «студийный» Spotify.

Поддерживаются отдельные треки. Альбомы и плейлисты Spotify пока не скачиваются — приложение покажет понятное сообщение.

## Tidal

LoadTube понимает ссылки:

- `tidal.com/browse/track/...`
- `tidal.com/browse/album/...`
- `tidal.com/browse/playlist/...`
- `tidal.com/browse/artist/...`
- `tidal.com/browse/mix/...`
- `tidal.com/browse/video/...`

При первом использовании приложение покажет код входа. Введите его на сайте Tidal — пароль вводится только там. После подтверждения ссылка начнёт скачиваться автоматически, а сессия сохранится между запусками.

Качество выбирается автоматически: Max (FLAC 24-bit), HiFi (FLAC), High (AAC 320) или Normal. Если тариф не поддерживает Max, приложение скачает лучшее доступное и покажет предупреждение.

Текстовый запрос в поле ввода открывает поиск по Tidal. Можно выбрать трек, альбом, плейлист, артиста или видео, а также загрузить свои плейлисты.

Альбом или плейлист выглядит одной строкой с общим прогрессом; список треков раскрывается. Уже скачанные файлы пропускаются. Для артиста можно выбрать конкретные альбомы.

По умолчанию файлы сохраняются так:

```text
Artist/Album (Year)/01 - Track.flac
Playlist/01 - Artist - Track.flac
```

Рядом лежит `cover.jpg`, теги и обложка встроены в файл. В настройках можно включить `.lrc`, плоскую структуру папок и скачивание видео.

## Обновления

LoadTube проверяет обновления через GitHub Releases:

- автоматически — не чаще одного раза в сутки, без блокировки интерфейса;
- вручную — шестерёнка → **«Проверить обновления»**, или меню приложения **LoadTube → Проверить обновления…**.

Если версия новее, появляется необязательное окно с описанием изменений. Можно нажать **«Позже»**, **«Пропустить эту версию»** или **«Скачать обновление»**. DMG скачивается в `~/Downloads`, проверяется через `hdiutil` и открывается; дальше вы сами перетаскиваете приложение в Applications.

Автопроверку можно отключить в настройках. Приложение не устанавливает обновления молча и не перезаписывает само себя.

## Язык интерфейса

По умолчанию интерфейс русский. В настройках (шестерёнка) можно выбрать **Русский**, **English** или **Системный** — переключение применяется сразу, без перезапуска, и сохраняется между запусками.

## Как это устроено

- `yt-dlp` скачивает видео и звук по отдельности, затем `ffmpeg` склеивает их (или конвертирует звук в MP3). Для Instagram это DASH-видео + аудио, для TikTok — готовый MP4 со звуком.
- Для TikTok формат `download` (с запечённым водяным знаком) исключён; используются чистые playback-потоки. Для Instagram и TikTok можно передать cookies браузера (`--cookies-from-browser`), чтобы скачивать закрытый контент и обходить анонимные лимиты.
- Файлы Instagram/TikTok после скачивания приводятся к совместимому с QuickTime виду — перепаковка, конвертация звука или транскод только при необходимости.
- Инструменты ищутся сначала в `~/Library/Application Support/LoadTube/bin`, затем в системе (Homebrew). При первом запуске портативные сборки скачиваются с GitHub (yt-dlp и ffmpeg-static).
- Прогресс читается из `--progress-template` в реальном времени.
- Итоговый путь берётся из `--print-to-file after_move:filepath`.
- Для Spotify метаданные берутся из oEmbed и JSON со страницы embed; поиск идёт через `ytsearch1:`; обложка и теги записываются `ffmpeg`.
- Для Tidal используется нативный клиент: device-code OAuth, API метаданных, `playbackinfo`, затем BTS-файл или DASH-сегменты. Зашифрованный FLAC расшифровывается AES-128-CTR, после чего `ffmpeg` пишет теги и обложку. Python и `tidal-dl` в приложение не входят.
- Приложение не в песочнице (sandbox), потому что запускает дочерние процессы `yt-dlp`/`ffmpeg`. Для личного использования это нормально.

## Решение проблем

| Проблема | Что делать |
|---|---|
| **YouTube что-то поменял, загрузка перестала работать** | Обновите yt-dlp. Портативная версия: удалите `~/Library/Application Support/LoadTube/bin` и переустановите инструменты при следующем запуске. Homebrew: `brew upgrade yt-dlp`. |
| **Instagram пишет, что доступ ограничен** | Instagram рейт-лимитит анонимов. Войдите на instagram.com в браузере и выберите его в **Настройки → Instagram и TikTok → Cookies браузера**. Safari нужен «Полный доступ к диску», Chrome может запросить «Связку ключей». |
| **TikTok скачался с водяным знаком** | Этого быть не должно: приложение исключает формат `download`. Проверьте, что yt-dlp свежий; если проблема осталась — пришлите ссылку на видео. |
| **TikTok скачался в 720p, хотя видео в 1080p** | TikTok отдаёт 1080p не для всех роликов; приложение берёт максимальное разрешение без водяного знака. |
| **TikTok/Instagram просят войти** | Войдите на сайте в выбранном браузере и повторите; cookies читаются в момент скачивания. |
| **QuickTime пишет, что файл содержит несовместимые медиа** | Приложение приводит файлы Instagram/TikTok к совместимому виду автоматически. Обновитесь до 1.3.1+; если повторится — пришлите ссылку. |
| **macOS не даёт запустить приложение** | Правой кнопкой по `LoadTube.app` → **«Открыть»**. Если всё равно блокирует: `xattr -dr com.apple.quarantine /Applications/LoadTube.app`. Приложение подписано ad-hoc; для нотаризации нужен Apple Developer ID. |
| **Файл «Максимум» не открывается в QuickTime** | Этот пресет сохраняет оригинальные кодеки (AV1/VP9/Opus). Для QuickTime выбирайте **4K MP4** или **1080p MP4**. |
| **«4K MP4» долго обрабатывается** | Это нормально: AV1/VP9 перекодируется в HEVC аппаратно, время зависит от длины и разрешения. |
| **Spotify-трек не находится** | Проверьте, что это ссылка на отдельный трек, а не альбом/плейлист; попробуйте другую ссылку или проверьте сеть. |
| **Spotify скачал другой трек** | Поиск идёт по названию и исполнителю на YouTube; для редких и кавер-версий результат может отличаться. |
| **Tidal пишет «доступен только фрагмент»** | На Free-тарифе Tidal отдаёт не весь трек. Нужен HiFi или Max. |
| **Tidal не входит по коду** | Проверьте, что код введён на сайте Tidal и не истёк (5 минут). Если сессия истекла, нажмите «Войти» в настройках. |
| **Tidal-трек недоступен в регионе** | Это ограничение Tidal, а не приложения. Попробуйте другую ссылку или аккаунт. |
| **Нужен другой язык** | Шестерёнка → **«Язык интерфейса»**. |
| **Видео с возрастным ограничением не качается** | Нужны cookies аккаунта. В приложении пока не поддерживается; можно вручную: `yt-dlp --cookies-from-browser chrome <ссылка>`. |
| **Нет уведомлений** | Разрешите их в **Системные настройки → Уведомления → LoadTube**. |

## Приватность

- Нет телеметрии и аналитики.
- Нет аккаунта внутри приложения (кроме собственного OAuth-входа Tidal, который проходит на сайте Tidal).
- Cookies браузера, если включены, читаются локально `yt-dlp` и отправляются только соответствующему сайту.
- Загрузки идут напрямую с сайта-источника на ваш Mac.

## Лицензия и благодарности

Проект для личного использования. Скачивайте только тот контент, на который у вас есть права.

Tidal-логика вдохновлена проектом [Tidal-Media-Downloader](https://github.com/yaronzz/Tidal-Media-Downloader) (Apache-2.0).  
Загрузка работает на [yt-dlp](https://github.com/yt-dlp/yt-dlp) и [FFmpeg](https://ffmpeg.org).

## История версий

### 1.3.1

- **Фикс совместимости с QuickTime** для Instagram/TikTok: HEVC `hev1` → `hvc1` без перекодирования, не-AAC звук → AAC, неподдерживаемые кодеки → HEVC, лишние дорожки убираются, `+faststart`.

### 1.3.0

- **Instagram Reels** — без водяного знака, со звуком, до 1080p.
- **TikTok** — без водяного знака, со звуком, до 1080p; формат `download` с вотермаркой исключён.
- **Cookies браузера** для Instagram/TikTok (Safari, Chrome, Firefox, Edge, Brave) с автоматическим фолбэком.
- Отдельные пресеты для коротких видео: **«Максимум»** и **«MP3»**.
