# LoadTube

Нативное приложение для macOS, которое скачивает видео и музыку с YouTube
(и других сайтов, которые поддерживает yt-dlp) в максимальном качестве.
Без рекламы, без регистрации, без браузера.

## Возможности

- **4 пресета качества**
  - **Максимум** — лучший видеопоток + лучший звук, до 8K/60fps/HDR,
    оригинальные кодеки (YouTube отдаёт AV1/VP9/Opus).
  - **4K MP4** — до 4K в контейнере MP4. Если YouTube отдаёт AV1/VP9,
    файл автоматически перекодируется в HEVC (H.265) через VideoToolbox,
    чтобы он открывался в QuickTime. Перекодирование занимает время.
  - **1080p MP4** — Full HD в MP4, всегда H.264 + AAC, открывается везде.
  - **MP3** — только звук в лучшем качестве, с обложкой и ID3-тегами.
- **Spotify-ссылки** — вставьте ссылку на трек, и LoadTube найдёт его на
  YouTube, скачает лучший доступный звук и подставит обложку и теги из Spotify.
- **Любые сайты, которые умеет yt-dlp** — SoundCloud, Bandcamp, VK и другие.
- Прогресс-бар с процентом, скоростью и оставшимся временем.
- Очередь: до двух загрузок одновременно, остальные ждут.
- Вставка ссылки из буфера обмена и drag & drop ссылки прямо в окно.
- Плейлисты: скачивание в отдельную папку с нумерацией.
- Уведомление по завершении, кнопки «Показать в Finder» и «Открыть файл».
- **Русский и английский интерфейс**, переключается в настройках на лету.
- Тёмная, светлая или системная тема (по умолчанию — тёмная).
- Папка загрузок на выбор (по умолчанию `~/Downloads`).
- Автоматическая установка инструментов при первом запуске — **без Homebrew**:
  приложение скачивает портативные `yt-dlp` и `ffmpeg` (~120 МБ) в
  `~/Library/Application Support/LoadTube/bin`. Если Homebrew установлен,
  доступен и резервный вариант установки через него.

## Установка (для получателей)

1. Откройте `LoadTube.dmg`.
2. Перетащите **LoadTube** в папку **Applications**.
3. Запустите приложение из Applications. Если macOS говорит, что разработчик
   не подтверждён: правой кнопкой по LoadTube → **«Открыть»** → **«Открыть»**
   (приложение подписано ad-hoc, без Developer ID и нотаризации).
4. При первом запуске нажмите «Установить автоматически» — приложение само
   скачает `yt-dlp` и `ffmpeg` (~120 МБ). Homebrew не нужен.

Готовый установщик лежит в `dist/LoadTube.dmg` — его можно передать другому
человеку или выложить. Внутри также есть короткая инструкция «Первый запуск».

## Требования

- macOS 14 (Sonoma) или новее.
- Интернет (для первого запуска и самих загрузок).
- Homebrew — **не обязателен**, но поддерживается как резервный способ.
- Для сборки из исходников: Xcode Command Line Tools / Swift 5.9+.

## Сборка

```bash
make app       # собрать build/LoadTube.app (universal: arm64 + x86_64)
make run       # собрать и запустить
make install   # собрать и установить в /Applications
make dmg       # собрать dist/LoadTube.dmg для распространения
make clean     # удалить артефакты сборки
```

Или одной командой, если хочется сразу установить:

```bash
make install
```

DMG для передачи другим людям:

```bash
make dmg
open dist/LoadTube.dmg
```

## Использование

1. Запустите **LoadTube**.
2. Вставьте ссылку на видео, плейлист или трек (можно перетащить её в окно).
3. Выберите качество и нажмите **«Скачать»** (или Enter).
4. Готово: файл лежит в выбранной папке, уведомление появится справа сверху.

Первый запуск: если в системе нет `yt-dlp` и `ffmpeg`, приложение покажет
экран установки и скачает портативные версии в
`~/Library/Application Support/LoadTube/bin` — Homebrew не обязателен.
Если Homebrew есть, можно выбрать и установку через него.

## Музыка и Spotify

LoadTube понимает ссылки вида `open.spotify.com/track/…` и короткие
`spotify.link/…`.

Spotify отдаёт музыку только через DRM, поэтому скачать оттуда звук напрямую
нельзя. Приложение делает так:

1. Достаёт название, исполнителя и обложку из публичных метаданных Spotify.
2. Ищет этот трек на YouTube (`ytsearch1`).
3. Скачивает лучший доступный аудиопоток и конвертирует его в MP3 VBR.
4. Переименовывает файл в «Исполнитель - Название» и подставляет обложку
   и ID3-теги из Spotify.

Важно: это **не оригинальный поток Spotify 320 kbps**. Качество ограничено
источником (обычно Opus 128–160 kbps на YouTube), поэтому итоговый MP3 —
максимально возможный из доступного, но не «студийный» Spotify.

Поддерживаются отдельные треки. Альбомы и плейлисты Spotify пока
не скачиваются — приложение покажет понятное сообщение.

## Язык интерфейса

По умолчанию интерфейс русский. В настройках (шестерёнка) можно выбрать
**Русский**, **English** или **Системный** — переключение применяется сразу,
без перезапуска. Выбор сохраняется между запусками.

## Как это устроено

- `yt-dlp` скачивает видеопоток и аудиопоток по отдельности, затем `ffmpeg`
  склеивает их в итоговый файл (или конвертирует звук в MP3).
- Инструменты ищутся сначала в `~/Library/Application Support/LoadTube/bin`,
  затем в системе (Homebrew). При первом запуске портативные сборки
  скачиваются с GitHub (yt-dlp и ffmpeg-static).
- Прогресс читается из `--progress-template` в реальном времени.
- Итоговый путь берётся из `--print-to-file after_move:filepath`.
- Для Spotify метаданные берутся из oEmbed и JSON со страницы embed,
  поиск идёт через `ytsearch1:`; обложка и теги перезаписываются ffmpeg.
- Приложение не в песочнице (sandbox), потому что запускает дочерние процессы
  `yt-dlp`/`ffmpeg`. Для личного использования это нормально.

## Решение проблем

- **YouTube что-то поменял, и загрузка перестала работать** — обновите yt-dlp.
  Если стоит портативная версия: удалите папку
  `~/Library/Application Support/LoadTube/bin` и перезапустите установку
  инструментов (приложение предложит это при следующем запуске). Если
  используете Homebrew: `brew upgrade yt-dlp`.
- **macOS не даёт запустить приложение** — правой кнопкой по `LoadTube.app` →
  «Открыть». Если всё равно блокирует:
  `xattr -dr com.apple.quarantine /Applications/LoadTube.app`.
  Приложение подписано ad-hoc; для нотаризации нужен Apple Developer ID.
- **Скачал «Максимум», а QuickTime не открывает файл** — этот пресет
  сохраняет оригинальные кодеки (AV1/VP9/Opus). Для QuickTime выбирайте
  «4K MP4» или «1080p MP4» — они совместимы.
- **«4K MP4» долго обрабатывается** — это нормально: AV1/VP9
  перекодируется в HEVC аппаратно, время зависит от длины и разрешения.
- **Spotify-трек не находится** — проверьте, что это ссылка на отдельный
  трек, а не альбом/плейлист; попробуйте другую ссылку или проверьте сеть.
- **Spotify-трек скачался, но это другой трек** — поиск идёт по названию и
  исполнителю на YouTube; для редких/кавер-версий результат может отличаться.
- **Нужен другой язык** — шестерёнка → «Язык интерфейса».
- **Видео с возрастным ограничением не качается** — нужны cookies аккаунта.
  В текущей версии это не поддерживается; можно скачать вручную:
  `yt-dlp --cookies-from-browser chrome <ссылка>`.
- **Нет уведомлений** — разрешите их в
  «Системные настройки → Уведомления → LoadTube».
- **macOS не даёт запустить приложение** — нажмите на `LoadTube.app`
  правой кнопкой → «Открыть». Приложение подписано ad-hoc, этого достаточно
  для локальной сборки.
